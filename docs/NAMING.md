# Naming

- `RSI` / `rsi` in product copy, dashboard, and Python modules under `research/rsi/` means **Relative Strength Index** only.
- The outer loop is **Recursive Self-Improvement** / `recursive_self_improvement`. Never `rsi`, `RSI`, or `harness_rsi` as a name for that loop.
- Promotion key is `(factor_id, sleeve_id)` where sleeve is `crypto_spot` | `us_equity` | `us_future`.
